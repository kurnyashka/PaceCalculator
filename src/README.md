# Pace Calculator 🏃‍♂️⏱️

Консольное приложение на Java для расчета целевого бегового темпа и подробной по-километровой раскладки (сплитов) на дистанции. Проект разработан с учетом специфики подготовки к беговым стартам.

## 🛠 Технологический стек
* **Java Core** (модификаторы доступа, статические методы, циклы, условные операторы)
* **OOP & Parsing** (`Scanner`, работа со строками через `.split()`, `Integer.parseInt()`)
* **Formatting** (`DecimalFormat`, `String.format`)

## 🚀 Как запустить
1. Убедитесь, что у вас установлена **Java 17** (или выше).
2. Клонируйте репозиторий или скачайте архив проекта.
3. Откройте проект в **IntelliJ IDEA**.
4. Запустите файл `src/Main.java`.

## 💡 Пример использования
**Ввод:**
* Дистанция: `10` (км)
* Желаемое время: `00:45:00`

**Вывод:**
```text
Ваш целевой темп: 4:30
Раскладка по км: 
1км   0:04:30
2км   0:09:00
3км   0:13:30
...
10км   0:45:00
```

## 👩‍💻 Автор
Разработано в рамках подготовки к соревновательным стартам и прокачки навыков бэкенд-разработки на Java.
